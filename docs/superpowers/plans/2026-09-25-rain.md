# Rain Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Rain in front of the wall, switched on and off from the menu (and from the screen saver's Options), that builds up, swells and eases on its own, glosses the leaves, dims the scene and keeps the butterflies away.

**Architecture:** A pure, seeded weather module (`rain-weather.js`) decides how hard it rains, how wet the leaves are and how overcast the scene is over time. A Three.js module (`rain.js`) draws streaks, ceiling drips and pebble splashes as instanced quads whose paths are computed on the GPU from time. `main.js` feeds the weather to the rain, leaves, photo and butterflies and exposes `wallSetRain(on)`; the wallpaper app sends it from a **Rain** menu item and the screen saver from a **Rain** checkbox in its Options.

**Tech Stack:** Three.js 0.186.0 (vendored), GLSL `ShaderMaterial`, Node's test runner, headless Chrome smoke test, Swift (AppKit, WebKit, ScreenSaver) with plain-program tests.

**Spec:** `docs/superpowers/specs/2026-09-25-rain-design.md` (builds on `2026-09-23-green-wall-design.md` and `2026-09-24-screen-saver-and-rename-design.md`).

All code below was built and run in a scratch copy of the repository before this plan was written: every `Expected:` line is what that copy printed, and every edit below reproduces that copy exactly.

## Review Focus

1. **A display connected while it rains** must start raining too: its wall receives Rain before its page has loaded. Pinned by Task 6: `--check` sets Rain before the page loads and expects the scene to report it.
2. **Turning Rain off** must stop it on every screen and let the leaves dry. Pinned by Task 1 (the weather thins within 8 s and dries within a minute) and Task 6 (`--check` turns rain off and expects `"rain":{"on":false`).
3. **Screen-saver copies in other processes** (a thumbnail in System Settings, pre-warmed full-screen copies) must follow Options, and a malformed or old-format broadcast (the previous build sent just `"1"`) must be ignored, not crash or misread. Pinned by Task 5's parser tests.
4. **Days of uptime**: the weather must not grow without bound and shader times must wrap. Pinned by Task 1 ("hours of rain keep only a few scheduled swells and bursts") and Task 2 (wrapped fall and wind time).
5. **Invisible rain**: wall y runs down and world y up, which flips the quads' winding; single-sided materials cull every streak (this happened while planning). Pinned by Task 2 ("every layer draws both sides").

```js
// How hard it rains, how wet the leaves are and how overcast the scene is, over time.
// Pure and seeded: rain.js, leaves.js and photo-layer.js only draw what this decides.
// Times are simulation seconds; at(t) must be called with non-decreasing t.
export const RAIN = {
  buildUp: 6,            // s from dry to steady rain
  taper: 8,              // s from steady rain to dry
  wetUp: 10,             // s for the leaves to get soaked
  dryOver: 60,           // s for them to dry once the rain has stopped
  base: 0.55,            // steady rain
  swell: 0.2,            // ± slow swells around it
  swellStep: [15, 25],   // s between the swells' control values
  burst: 0.45,           // added at a burst's peak
  burstEvery: [180, 480],
  burstLength: [15, 40],
  floor: 0.3,            // never lighter than this while it rains (after the build-up)
};

const STEP = 0.1;        // s; at(t) integrates in steps no longer than this
const smooth = (u) => u * u * (3 - 2 * u);

export function createRainWeather(random) {
  const R = RAIN;
  let now = 0, raining = false, ramp = 0, wet = 0;
  // Swells: control values in [-1, 1], eased between; bursts: start and length.
  const swells = [{ t: 0, v: random.range(-1, 1) }];
  const bursts = [];
  let nextBurst = random.range(...R.burstEvery);

  function swellAt(t) {
    while (swells[swells.length - 1].t <= t) {
      const last = swells[swells.length - 1];
      swells.push({ t: last.t + random.range(...R.swellStep), v: random.range(-1, 1) });
    }
    while (swells.length > 2 && swells[1].t <= t) swells.shift();
    const [a, b] = swells;
    return a.v + (b.v - a.v) * smooth((t - a.t) / (b.t - a.t));
  }

  function burstAt(t) {
    while (nextBurst <= t) {
      bursts.push({ start: nextBurst, length: random.range(...R.burstLength) });
      nextBurst += random.range(...R.burstEvery);
    }
    while (bursts.length && bursts[0].start + bursts[0].length < t) bursts.shift();
    const b = bursts[0];
    if (!b || t < b.start) return 0;
    return 0.5 - 0.5 * Math.cos((2 * Math.PI * (t - b.start)) / b.length);   // 0 → 1 → 0
  }

  function advance(t) {
    while (now < t) {
      const dt = Math.min(STEP, t - now);
      ramp = raining ? Math.min(1, ramp + dt / R.buildUp) : Math.max(0, ramp - dt / R.taper);
      wet = ramp > 0 ? Math.min(1, wet + dt / R.wetUp) : Math.max(0, wet - dt / R.dryOver);
      now += dt;
    }
  }

  return {
    /** Rain on or off from simulation time t; it builds up or thins out from where it is. */
    setRaining(on, t) {
      advance(t);
      raining = Boolean(on);
    },
    get raining() { return raining; },
    /** This moment's weather: level (how hard it rains), wet, overcast; each 0..1. */
    at(t) {
      advance(t);
      const steady = Math.min(1, Math.max(R.floor, R.base + R.swell * swellAt(t) + R.burst * burstAt(t)));
      return { level: ramp * steady, wet, overcast: ramp };
    },
    /** Swells and bursts held in memory (stays small over hours of rain). */
    get scheduled() { return swells.length + bursts.length; },
  };
}
```

import * as THREE from '../vendor/three.module.js';
import { WALL_H, LIGHTS } from './wall.js';
import { shaderTime, SHADER_TIME_WRAP } from './wind.js';
import { WIND_GLSL } from './photo-layer.js';

// Rain in front of the wall: streaks in three depths, drips from the ceiling's beam and
// splashes on the pebbles. Each drop's path is a function of time, worked out on the GPU;
// a drop shows while rain-weather.js's level is above its own threshold.
export const DEPTHS = [   // share of the streaks, length, speed (units/s), opacity, width (device px)
  { share: 0.45, length: [14, 22], speed: [700, 850], opacity: [0.10, 0.16], width: 1 },
  { share: 0.35, length: [22, 32], speed: [850, 1050], opacity: [0.16, 0.24], width: 1 },
  { share: 0.20, length: [32, 48], speed: [1050, 1300], opacity: [0.22, 0.32], width: 1.5 },
];
export const COUNTS = { streaks: 1800, drips: 40, splashes: 120, droplets: 3 };
const TOP = -60, BOTTOM = WALL_H + 60;     // streaks fall from above the view to below it
const BEAM = 31, PEBBLES = [985, 1025];    // the ceiling beam's lower edge; the pebble band
const f = (v) => v.toFixed(1);

const COMMON = /* glsl */ `
  ${WIND_GLSL}
  uniform float uFall, uLevel, uPxPerUnit, uStrength;
  // Hash of two numbers in [0, 1); arguments kept small so 32-bit sin stays accurate.
  float hash2(float a, float b) { return fract(sin(mod(a, 289.0) * 12.9898 + mod(b, 289.0) * 78.233) * 43758.5453); }
  // The rain's lean at wall x: a little always, more as a gust passes (the wind blows left to right).
  float slant(float x) { return radians(clamp(6.0 + uStrength * (14.0 * gustAt(x, 0.0) + 3.0 * swayAt(x, 0.0)), 0.0, 25.0)); }
  vec4 place(vec2 wall) { return projectionMatrix * viewMatrix * vec4(wall.x, -wall.y, 0.0, 1.0); }
  const vec4 HIDDEN = vec4(2.0, 2.0, 2.0, 1.0);   // outside the view: nothing is rasterised
`;

// The downlights' cones, the shape lights.js draws: a streak inside one is brighter and warmer.
const LIGHT_GLSL = /* glsl */ `
  uniform vec2 uLights[${LIGHTS.length}];
  float lightAt(vec2 p) {
    float sum = 0.0;
    for (int i = 0; i < ${LIGHTS.length}; i++) {
      vec2 d = p - uLights[i];
      if (d.y <= 0.0) continue;
      float width = 24.0 + d.y * 0.3;
      sum += exp(-1.6 * (d.x / width) * (d.x / width)) * exp(-d.y / 240.0) * smoothstep(0.0, 30.0, d.y);
    }
    return min(sum, 1.0);
  }
  vec3 rainColour(vec2 p, float alpha) {
    float l = lightAt(p);
    return mix(vec3(0.80, 0.86, 0.92), vec3(1.0, 0.92, 0.78), l) * alpha * (1.0 + 1.5 * l);
  }
`;

const STREAK_VERTEX = /* glsl */ `
  ${COMMON}
  attribute vec2 aCorner;   // across (-0.5..0.5), along (0 tail .. 1 head)
  attribute vec4 iDrop;     // seed, phase (0..1), speed, length
  attribute vec3 iLook;     // opacity, width (device px), threshold
  varying float vAlpha, vAlong;
  varying vec2 vWall;
  void main() {
    vAlpha = iLook.x * smoothstep(iLook.z, iLook.z + 0.04, uLevel);
    if (vAlpha <= 0.0) { gl_Position = HIDDEN; return; }
    float span = ${f(BOTTOM - TOP)} + iDrop.w;
    float cycles = uFall * iDrop.z / span + iDrop.y;
    float n = floor(cycles);
    float x0 = -250.0 + 2100.0 * hash2(iDrop.x, n);   // a new place on every fall
    float y = ${f(TOP)} + fract(cycles) * span;
    float a = slant(x0);
    vec2 dir = vec2(sin(a), cos(a));
    vec2 head = vec2(x0 + (y - ${f(TOP)}) * tan(a), y);
    vec2 p = head - dir * iDrop.w * (1.0 - aCorner.y) + vec2(dir.y, -dir.x) * aCorner.x * iLook.y / uPxPerUnit;
    vAlong = aCorner.y;
    vWall = p;
    gl_Position = place(p);
  }`;

const STREAK_FRAGMENT = /* glsl */ `
  ${LIGHT_GLSL}
  varying float vAlpha, vAlong;
  varying vec2 vWall;
  void main() {
    float fade = smoothstep(0.0, 0.5, vAlong) * (1.0 - smoothstep(0.8, 1.0, vAlong));
    gl_FragColor = vec4(rainColour(vWall, vAlpha * fade), 1.0);
    #include <colorspace_fragment>
  }`;

const DRIP_VERTEX = /* glsl */ `
  ${COMMON}
  attribute vec2 aCorner;
  attribute vec4 iDrip;     // x, period (s), phase (0..1), threshold
  varying float vAlpha, vAlong;
  varying vec2 vWall;
  const float G = 2500.0;
  void main() {
    float fall = sqrt(2.0 * (${f(PEBBLES[0] + 15)} - ${f(BEAM)}) / G);
    float cycles = uFall / iDrip.y + iDrip.z, n = floor(cycles), tau = fract(cycles) * iDrip.y;
    // Heavier rain: more of the drip's cycles release a drop.
    float due = iDrip.w * (0.4 + 0.6 * hash2(iDrip.x, n));
    vAlpha = tau < fall ? 0.5 * smoothstep(due, due + 0.04, uLevel) : 0.0;
    if (vAlpha <= 0.0) { gl_Position = HIDDEN; return; }
    float y = ${f(BEAM)} + 0.5 * G * tau * tau, a = slant(iDrip.x), len = mix(8.0, 12.0, hash2(iDrip.x, n + 7.0));
    vec2 dir = vec2(sin(a), cos(a));
    vec2 head = vec2(iDrip.x + (y - ${f(BEAM)}) * tan(a), y);
    vec2 p = head - dir * len * (1.0 - aCorner.y) + vec2(dir.y, -dir.x) * aCorner.x * 2.0 / uPxPerUnit;
    vAlong = aCorner.y;
    vWall = p;
    gl_Position = place(p);
  }`;

const SPLASH_VERTEX = /* glsl */ `
  ${COMMON}
  attribute vec2 aCorner;
  attribute vec4 iSplash;   // seed, period (s), phase (0..1), threshold
  attribute vec3 iHop;      // sideways (-1..1), height (units), size (device px)
  varying float vAlpha;
  varying vec2 vCorner, vWall;
  const float LIFE = 0.25, G = 600.0;
  void main() {
    float cycles = uFall / iSplash.y + iSplash.z, n = floor(cycles), tau = fract(cycles) * iSplash.y;
    float due = iSplash.w * (0.4 + 0.6 * hash2(iSplash.x, n));
    vAlpha = tau < LIFE ? 0.35 * (1.0 - tau / LIFE) * smoothstep(due, due + 0.04, uLevel) : 0.0;
    if (vAlpha <= 0.0) { gl_Position = HIDDEN; return; }
    vec2 base = vec2(1600.0 * hash2(iSplash.x, n + 3.0), mix(${f(PEBBLES[0])}, ${f(PEBBLES[1])}, hash2(iSplash.x, n + 5.0)));
    float up = sqrt(2.0 * G * iHop.y) * tau - 0.5 * G * tau * tau;
    vec2 p = base + vec2(iHop.x * 8.0 * tau / LIFE, -up) + vec2(aCorner.x, aCorner.y - 0.5) * iHop.z / uPxPerUnit;
    vCorner = vec2(aCorner.x, aCorner.y - 0.5);
    vWall = p;
    gl_Position = place(p);
  }`;

const SPLASH_FRAGMENT = /* glsl */ `
  ${LIGHT_GLSL}
  varying float vAlpha;
  varying vec2 vCorner, vWall;
  void main() {
    float round = 1.0 - smoothstep(0.3, 0.5, length(vCorner));

/** A quad as instanced geometry: aCorner x across (-0.5..0.5), y along (0..1). */
function quads(count, attributes) {
  const g = new THREE.InstancedBufferGeometry();
  g.setAttribute('aCorner', new THREE.Float32BufferAttribute([-0.5, 0, 0.5, 0, 0.5, 1, -0.5, 1], 2));
  g.setAttribute('position', new THREE.Float32BufferAttribute(new Float32Array(12), 3));
  g.setIndex([0, 1, 2, 0, 2, 3]);
  for (const [name, size, values] of attributes) g.setAttribute(name, new THREE.InstancedBufferAttribute(new Float32Array(values), size));
  g.instanceCount = count;
  return g;
}

export function createRain(random) {
  const C = COUNTS;
  const drop = [], look = [];
  for (const d of DEPTHS) {
    for (let i = 0; i < Math.round(C.streaks * d.share); i++) {
      drop.push(random.range(0, 289), random.next(), random.range(...d.speed), random.range(...d.length));
      look.push(random.range(...d.opacity), d.width, random.next());
    }
  }
  const drip = [];
  for (let i = 0; i < C.drips; i++) drip.push(((i + random.range(0.1, 0.9)) / C.drips) * 1600, random.range(1.5, 4), random.next(), random.next());
  const splash = [], hop = [];
  for (let i = 0; i < C.splashes; i++) {
    const s = [random.range(0, 289), random.range(0.6, 1.6), random.next(), random.next()];
    for (let k = 0; k < C.droplets; k++) {
      splash.push(...s);
      hop.push(random.range(-1, 1), random.range(6, 14), random.range(1.5, 2.5));
    }
  }

  const uniforms = {
    uTime: { value: 0 }, uGustStart: { value: -1e4 }, uGustStrength: { value: 0 },
    uFall: { value: 0 }, uLevel: { value: 0 }, uPxPerUnit: { value: 1 }, uStrength: { value: 1 },
    uLights: { value: LIGHTS.map(([x, y]) => new THREE.Vector2(x, y)) },
  };
  const layer = (geometry, vertexShader, fragmentShader, order) => {
    const mesh = new THREE.Mesh(geometry, new THREE.ShaderMaterial({
      uniforms, vertexShader, fragmentShader,
      // Wall y runs down and world y up, so the quads' winding flips: draw both sides.
      side: THREE.DoubleSide, transparent: true, blending: THREE.AdditiveBlending, depthTest: false, depthWrite: false,
    }));
    mesh.frustumCulled = false;
    mesh.renderOrder = order;
    return mesh;
  };
  const group = new THREE.Group();
  group.add(
    layer(quads(drop.length / 4, [['iDrop', 4, drop], ['iLook', 3, look]]), STREAK_VERTEX, STREAK_FRAGMENT, 102),
    layer(quads(C.drips, [['iDrip', 4, drip]]), DRIP_VERTEX, STREAK_FRAGMENT, 101),
    layer(quads(C.splashes * C.droplets, [['iSplash', 4, splash], ['iHop', 3, hop]]), SPLASH_VERTEX, SPLASH_FRAGMENT, 100),
  );
  group.visible = false;

  return {
    group,
    /** t: simulation time (drops fall at their own speed); windTime and gust: the wind's
     *  (for the slant); weather: rain-weather.js's at(t); strength: the Motion setting's. */
    update(t, windTime, gust, weather, strength, pxPerUnit) {
      group.visible = weather.level > 0;
      if (!group.visible) return;
      const wind = shaderTime(windTime, gust);
      uniforms.uTime.value = wind.time;
      uniforms.uGustStart.value = wind.gustStart;
      uniforms.uGustStrength.value = gust.strength;
      uniforms.uFall.value = t % SHADER_TIME_WRAP;
      uniforms.uLevel.value = weather.level;
      uniforms.uStrength.value = strength;
      uniforms.uPxPerUnit.value = pxPerUnit;
    },
  };
}

// The screen saver's own settings, edited in its Options sheet and stored with
// ScreenSaverDefaults under the saver's module name (in legacyScreenSaver's container).
import ScreenSaver

struct SaverSettings {
  static let shared = SaverSettings(module: "local.cefalo-living-wall.saver")
  let module: String

  // Read fresh each time, so a long-running host sees what Options saved elsewhere.
  var motion: Int {
    get { motionLevel(stored: stored()?.object(forKey: "motion") as? Int) }
    nonmutating set { save(newValue, forKey: "motion") }
  }

  var rain: Bool {
    get { stored()?.bool(forKey: "rain") ?? false }
    nonmutating set { save(newValue, forKey: "rain") }
  }

  private func stored() -> UserDefaults? { ScreenSaverDefaults(forModuleWithName: module) }

  /// One instance for both calls: ScreenSaverDefaults drops a change that the same instance
  /// never synchronizes.
  private func save(_ value: Any, forKey key: String) {
    let defaults = stored()
    defaults?.set(value, forKey: key)
    defaults?.synchronize()
  }
}

## 13. Amendments while planning (2026-09-25)

Found while building the plan's code in a scratch copy; the plan implements these.

| Change | Why |
|---|---|
| `rain.update(t, windTime, gust, weather, strength, pxPerUnit)` | The slant uses the shared wind, whose shaders need the wind's own time (the Motion clock); drops fall on simulation time |
| The rain group is hidden while `level` is 0, even while the leaves are still wet | Nothing falls at level 0; the wet leaves are `leaves.js`'s |
| Splashes: 120, drawn as 360 droplet sprites (three each); about 2,200 quads in all | Each droplet hops on its own path |
| Render order: splashes 100, drips 101, streaks 102 | Streaks on top |
| Every rain material draws both sides | Wall y runs down and world y up, which flips the quads' winding; single-sided, every streak was culled |
| The rain has its own seeds (`SEED + 2` weather, `SEED + 3` drawing) | The shared generator also feeds the wind's gust schedule; rain must not change the dry scene |
| `--check` sets Rain before the page loads and turns it off at the end | A display connected while it rains must rain too; turning it off must reach the page |
| Browser: `?rain=1` starts it raining (also for frozen `?t=` frames), R toggles it | Screenshots and trying it out |
